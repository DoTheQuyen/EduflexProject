# Key concepts

Four things explain most of what you see in the Student Portal.

**Application**
: Your request to study a course. An application moves through a series of
  statuses from the moment you submit it. See
  [Track application status](../applications/track-application-status.md).

**Form**
: A questionnaire attached to an application. Your provider builds forms from a
  template, so the questions differ between providers and course types. See
  [Submit a form request](../forms/submit-a-form-request.md).

**Enrolment**
: Created by staff once an application is accepted. It records the course, the
  dates and your progress through it.

**Role and permissions**
: What you are allowed to see and do. Your role is set by an administrator, and
  it decides which menu items appear.

::: info
Permissions are read when you sign in. If an administrator changes your
access while you are signed in, sign out and back in to pick it up.
:::
