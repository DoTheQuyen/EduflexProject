# Your dashboard

**Who can do this:** Student
**Where:** Student Portal → **Dashboard**

The screen you land on after signing in.

## Total Applications

A count of your applications, broken down by status — **Approved**,
**Rejected** and **Studying**.

## Recent Applications

Your most recent applications with their statuses. **View all →** opens the full
[Application](applications/track-application-status.md) list.

If you have an application in progress, **Continue Application →** takes you
straight back to it.

## No active application

When nothing is in progress you see **No active application** and *Start a new
application whenever you're ready.*

That message means you are free to apply — you only see it when nothing is
Pending or Approved. See
[Create an application](applications/create-an-application.md).

## Quick Links

Shortcuts to **My Applications**, **My Courses** and **My Profile**.

## Good to know

A short panel of guidance for applicants.
