# Statuses

The status values you will see in the Student Portal.

## Application

An application is your request to study; an enrolment is created by your
provider once it is accepted. They have separate status sets.

| Status | Meaning | Can you start another application? |
|---|---|---|
| **Pending** | Submitted, waiting on the admissions team. | No |
| **Approved** | Accepted, being progressed to enrolment. | No |
| **Rejected** | Not successful. | Yes |
| **Studying** | You have been enrolled and are studying. | Yes |

You can edit or delete your own application only while it is **Pending**.

## Enrolment

Shown as the progress stepper on your application, once your provider creates
an enrolment for you.

| Status | Meaning |
|---|---|
| Draft | Created but not yet issued to you. |
| Offer | An offer has been made. |
| CoE | A Confirmation of Enrolment has been issued. |
| Apply Visa | A visa application is under way. |
| Visa Success | The visa was granted. |
| Visa Fail | The visa was refused. |
| Cancel | The enrolment was cancelled. |
| Completed | You finished the course. |
| Finalized | All administrative work is closed out. |

If your enrolment is cancelled or unsuccessful, the stepper is replaced by a
message asking you to contact your counsellor.

## Form

| Status | Meaning |
|---|---|
| **Requesting** | Sent to you, not yet started. |
| **Draft** | You have saved answers but not submitted. Still editable. |
| **Responded** | Submitted. You can view it but not edit it unless staff reopen it. |
| **Withdrawn** | Recalled by staff before you completed it. |
| **Archived** | Kept for the record, no longer active. |
