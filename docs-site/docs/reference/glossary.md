# Glossary

**Application**
: A student's request to study a course. Progresses through statuses and can
  carry forms and documents.

**CoE — Confirmation of Enrolment**
: The document issued once a student's place in a course is confirmed. An
  enrolment status value.

**Commission record**
: A finance record capturing what is owed to or by a partner in relation to an
  enrolment.

**Department**
: A grouping of users. Used for scoping the **All Tasks** view.

**Dynamic form**
: A questionnaire built from a form template and attached to a record for a
  student to complete.

**Enquiry**
: An initial contact from a prospective student, before any application exists.

**Enrolment**
: The record of a student studying a specific course, created once an
  application is accepted.

**Form response**
: One student's answers to one form. Has its own status, separate from the
  template it came from.

**Migration case**
: A visa matter tracked as an ordered series of steps, created from a visa
  process template.

**MIR — More information required**
: An enquiry status meaning the enquirer has been asked for more detail.

**Permission key**
: A single named grant, such as `EnrolmentsEdit`. Keys are attached to roles.

**Practitioner tag**
: A label from a small admin-managed catalog, used alongside visa process
  configuration.

**Role**
: A named set of permission keys. Every user has one.

**Template**
: A reusable definition — of a form, a visa process, an email or an invoice —
  that new records are created from. Editing a template does not rewrite
  records already created from it.
