# Complete your profile

**Who can do this:** Any signed-in user
**Where:** Sidebar → **Profile**
**Before you start:** Nothing.

The page has two cards: **Personal Information** and **Security**.

## Personal Information

In view mode the card shows:

| Field | Editable |
|---|---|
| First Name | Yes |
| Last Name | Yes |
| Email Address | Yes |
| Role | No — shown as a badge |
| Account Created | No |
| Last Login | No |

Fields you have not filled in show *Not set*.

### Edit your details

1. Select **Edit Profile**.
2. Change First Name, Last Name or Email Address. All three are required.
3. Select **Save Changes**, or **Cancel** to discard.

**Result:** A confirmation message appears at the top of the page. Your name in
the portal header updates.

The **Role** field is shown in edit mode too, but disabled, with the note *Role
cannot be changed*. Only an administrator can change it — contact your
education provider if your role is wrong.

## Security — change your password

1. Select **Change Password**.
2. Enter your **Current Password**.
3. Enter a **New Password**. It must be at least 6 characters.
4. Repeat it in **Confirm New Password**.
5. Select **Change Password**.

**Result:** A confirmation message appears inside the Security card.

::: info
**Edit Profile** and **Change Password** cannot be open at the same time —
starting one hides the other button until you finish or cancel.
:::

## Why this matters before applying

Your name and email are copied onto every application you create, in the
**Applicant Details** panel, and cannot be edited there. Get them right here
first — see [Create an application](../applications/create-an-application.md).

Your addresses and emergency contact are **not** stored on your profile. They
are captured per application, because they describe your situation at the time
you applied.
