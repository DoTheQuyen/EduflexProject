## Finding the right page fast

Every screen in the portal has a **?** button in the top-right corner of the
header. Selecting it opens the help topic for that exact screen, so you rarely
need to search.

## About this documentation

::: info Students read a different site
This is the **staff manual**, and it contains every topic — including the
student pages, so you can see exactly what an applicant is being told.

Students are sent to a separate **student manual** built from the same
source, containing only the student topics. The **?** button in the portal
picks the right one from the signed-in user's role, so a student never
lands here.
:::

- **Applies to:** Eduflex — see [Release notes](release-notes.md) for what
  changed in each version.
- **Does not cover:** installation, hosting and API integration. Those are in
  the internal technical documentation set.
- **Illustrations** are annotated wireframes rather than screenshots. They show
  layout and controls, not live data, so they stay accurate across releases and
  never leak anyone's records. Where a page has one, the numbered markers match
  the list beneath it.
