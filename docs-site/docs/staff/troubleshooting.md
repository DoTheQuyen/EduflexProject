# Troubleshooting

| Symptom | Likely cause | What to do |
|---|---|---|
| A menu section is missing | Your role lacks the permission, or it was granted after you signed in. | Sign out and back in, then ask an administrator to check your role. |
| A student cannot see a form you attached | The form template is not published, or it is attached to a different application. | Check the template's state and the application it is attached to. |
| A status you expect is not offered | That transition is not allowed from the current status. | See [Statuses](../reference/statuses.md). |
| A student's changes are not visible | They saved a draft but have not submitted. | Ask them to select **Submit**. |
| Notifications stop arriving | The real-time connection dropped. | Reload the page. |
