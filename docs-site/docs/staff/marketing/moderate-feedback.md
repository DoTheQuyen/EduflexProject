# Manage student feedback

**Who can do this:** Staff with `FeedbackView`, plus Add/Edit/Delete as needed
**Where:** Staff Portal → **Marketing** → **Feedback**

Feedback entries appear on the **public** feedback wall. Everything here is
published.

## Add or edit an entry

| Field | Required | Error if missing |
|---|---|---|
| **Name** | Yes | *Name is required* |
| **Course Name** | Yes | *Course name is required* |
| **Photo** | Yes | *Photo is required* |
| **Comment** | Yes | |

Photo uploads follow the limits in the **Images** tab of
[App settings](../../admin/settings/app-settings.md).

## How many appear publicly

The public carousel shows the number set in **Feedback carousel — default
count** in [App settings](../../admin/settings/app-settings.md). Entries beyond
that are stored but not shown.

## Before you publish

Every entry names a real person alongside their photo and course, on a public
page.

- Confirm the student agreed to their name and photo being published, and keep
  a record of it — nothing in Eduflex stores that consent for you.
- If a student later asks to be removed, delete the entry here. There is no
  hide-without-deleting option.

::: info This is publishing, not record-keeping
The feedback wall is marketing copy. Substantive complaints or requests
from students belong in [Enquiries](../enquiries/manage-enquiries.md) or as
a [task](../tasks/manage-tasks.md), where they get worked and audited —
not on a public wall.
:::
