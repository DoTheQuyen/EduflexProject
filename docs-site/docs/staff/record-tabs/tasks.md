# Tasks tab

**Where:** The **Tasks** tab on an enrolment, a migration case or a financial
record.

Shows only the tasks linked to the record you are looking at, using the same
task list as the main **Tasks** menu.

## Layout

| Control | What it does |
|---|---|
| **Active** / **Completed** tabs | Switch between open and finished tasks. |
| **New Task** | Creates a task already linked to this record. Appears only if you can add tasks. |
| Search box | *Search tasks…* |
| Refresh and pager | The list is paged. |

Empty, it reads *No tasks found.*

## Creating a task from a record

This is the better way to raise a task. Selecting **New Task** here pre-fills
the link to the record and **locks it** — the **Remove** control is hidden for
that link, so the connection cannot be lost by accident.

Creating the same task from the main **Tasks** menu means picking the record
manually from a picker, which is slower and easy to get wrong.

Everything else about the task — assignee, due date, notes, reassignment,
completion — works exactly as described in
[Manage tasks](../tasks/manage-tasks.md).

## Why it matters

The Tasks tab is what turns "someone should chase this" into something that
appears in a named person's **My Tasks** with a due date. A note on the
[Audit Trail](activity-log.md) records that something happened; a task makes
sure something happens next.
