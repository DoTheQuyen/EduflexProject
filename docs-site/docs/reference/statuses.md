# Statuses

Every status value in Eduflex and what it means.

## Application

Applications and enrolments have separate status sets. An application is the
student's request; an enrolment is created by staff once it is accepted.

| Status | Meaning | Student may start another application |
|---|---|---|
| Pending | Submitted, waiting on the admissions team. | No |
| Approved | Accepted, being progressed to enrolment. | No |
| Rejected | Not successful. | Yes |
| Studying | Staff have enrolled the student. | Yes |

Students can edit or delete their own application only while it is **Pending**.

## Enrolment

| Status | Meaning |
|---|---|
| Draft | Created but not yet issued to the student. |
| Offer | An offer has been made. |
| CoE | A Confirmation of Enrolment has been issued. |
| Apply Visa | A visa application is under way. |
| Visa Success | The visa was granted. |
| Visa Fail | The visa was refused. |
| Cancel | The enrolment was cancelled. |
| Completed | The student finished the course. |
| Finalized | All administrative and financial work is closed out. |

## Enquiry

| Status | Meaning |
|---|---|
| New | Received, not yet actioned. |
| MIR | More information required from the enquirer. |
| Responded | A reply has been sent. |
| Converted | The enquiry became a student or an application. |

## Form response

| Status | Meaning |
|---|---|
| Requesting | Sent to the student, not yet opened or answered. |
| Draft | The student has started answering but has not submitted. |
| Responded | Submitted. The student can no longer edit it unless staff reopen it. |
| Withdrawn | Recalled before it was completed. |
| Archived | Retained for the record, no longer active. |

## Task

| Status | Meaning |
|---|---|
| New | Created and assigned, not yet started. |
| Processing | The assignee is working on it. |
| Completed | Finished. |

Task history also records why an entry was added: a plain **Note**, a
**Status Change**, or a **Reassign**.

## Template status

Form templates and visa process templates share the same two states.

| Status | Meaning |
|---|---|
| Active | Available to be used on new records. |
| Inactive | Hidden from new records. Records already created from it are unaffected. |

## Role types

| Role type | Typical audience |
|---|---|
| Admin | Full administration, including roles and permissions. |
| Manager | Oversight across a department, including **All Tasks**. |
| Staff | Day-to-day operational work. |
| Student | The Student Portal only. |
| Customer | External party with limited access. |
